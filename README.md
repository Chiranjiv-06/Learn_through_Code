# Learn Through Code

A personal repository for practicing and learning web development concepts using HTML, CSS, and JavaScript.

## 📚 About

This repository contains small practice projects, experiments, and coding exercises created while learning front-end development.

The goal of this repository is to:
- Improve HTML, CSS, and JavaScript skills
- Experiment with new concepts
- Build small practice applications
- Track learning progress

## 📁 Project Structure

```
Learn_Through_Code/
│── index.html      # Main page
│── alice.html      # Practice page
│── bob.html        # Practice page
│── style.css       # Styling
│── run.js          # JavaScript functionality
```

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/Chiranjiv-06/Learn_Through_Code.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
