# Hands-on Web Development & Showcase

A repository of web development projects, modular UI components, knowledge checks, and coding practice using semantic HTML5, CSS3, modern JavaScript, and Git.

## Project Structure

- `index.html` - Main landing page and project showcase overview.
- `alice.html` - Interactive knowledge-check module and assessment interface.
- `bob.html` - Case study showcase with interactive performance telemetry data.
- `style.css` - Central stylesheet containing color themes, responsive layouts, and typography.
- `run.js` - Script handling client-side interactions, quiz validation, and dynamic card metrics.
